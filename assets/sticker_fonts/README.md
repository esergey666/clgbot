# Sticker fonts

Roboto Condensed from https://github.com/google/fonts/tree/main/ofl/robotocondensed (SIL OFL, see OFL.txt).
The variable source is retained. Static instances used by Pillow: Regular at weight 500, Bold at weight 650. Generated with fontTools.varLib.instancer. No glyph outline edits. Barcode digits and service numbers use the existing Inconsolata fonts with a slashed zero and their bundled OFL license.
