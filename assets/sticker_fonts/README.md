# Sticker fonts

Roboto Condensed from https://github.com/google/fonts/tree/main/ofl/robotocondensed (SIL OFL, see OFL.txt).
The variable source is retained. Static instances used by Pillow: Regular at weight 500, Bold at weight 650. Generated with fontTools.varLib.instancer. No glyph outline edits. EAN legends use the custom 5 x 7 bitmap alphabet in bot/receipts/pixel_digits.py. The upper service number uses bundled Inconsolata Bold with a slashed zero. Other lines use individually calibrated Roboto Condensed widths and heights.
