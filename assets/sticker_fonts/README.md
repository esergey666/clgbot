# Sticker fonts

Roboto Condensed from https://github.com/google/fonts/tree/main/ofl/robotocondensed (SIL OFL, see OFL.txt).
The variable source is retained. Static instances used by Pillow: Regular at weight 500, Bold at weight 650. Generated with fontTools.varLib.instancer. No glyph outline edits. Barcode digits use the existing Receipt Mono font and its bundled license.
